# Workspace — Founder

Briefs the CEO has put to the founder, archived so there is a record of what was asked, what was recommended, and what was decided.

**Members (read + write):** `ceo`
**Additional readers:** —
**Owner:** `ceo`

The **founder** reads and writes anywhere in this repository; nothing here constrains the human. No agent other than the CEO writes in this room.

## Layout

```
briefs/     founder briefs, newest by filename date: YYYY-MM-DD-<slug>.md
```

## Rules

- One file per brief, in the CEO format from `.claude/agents/ceo.md`.
- A brief records what was recommended and, once the founder responds, what was decided — then the decision goes to `governance/decision-log.md` and any signature to `governance/approvals/`.
- The CEO never writes a founder decision here that the founder did not actually give.
