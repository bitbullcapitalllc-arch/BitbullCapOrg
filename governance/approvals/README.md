# Signed Approval Records

One file per approval: `YYYY-MM-DD-<short-slug>.md`, copied from `governance/templates/`.

- **Do not edit a signed record.** Amendments append to the record's amendment table with their own signatures; a replaced record gets `SUPERSEDED BY <id>` at the top.
- **Nobody fills in another party's signature line** — and no agent ever fills in the founder's.
- The `trader` reads these records to decide whether it may act. A record that is incomplete, expired, or silent on a limit means **no**.

This directory is empty until the first approval is signed.
